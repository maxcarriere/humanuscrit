# Skills Humanuscrit

Compétences au format [Agent Skills](https://agentskills.io) publiées par Humanuscrit.

- `humanuscrit-submit` : soumettre un texte en français à la plateforme d'Humanuscrit via le protocole HAPP.

Installation avec la CLI skills : `npx skills add maxcarriere/humanuscrit`

Index machine : https://api.humanuscrit.com/.well-known/skills/index.json (copie servie par l'API ; le site Jekyll exclut ce dossier pour ne pas consommer le front matter).
